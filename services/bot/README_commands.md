# services/bot — NoneBot2 插件（B50 / 发票 / 队列通知）

VirtualWait QQ 机器人（services/bot，NoneBot2）：QQ 扫码查询完整 B50 成绩图（每次新码，查完自动登出）；发票命令保留。

## 命令

| 命令 | 说明 | 登录 |
|------|------|------|
| `/help` | 全部命令说明 | - |
| `/b50 <二维码>` | 完整 B50 图（FC/AP/同步/DX 徽标，查完自动登出） | 登录态（每次新码） |
| `/fp <二维码> [2~5]` | 发票（库存 0 才下发，免费固定 1 张） | 写（每次新码） |

> 群里需 @机器人；私聊直接发。写命令真实改写账号数据，确认是自己的账号再发。
> 写操作约需 1 分钟（含服务器时序要求的 60s 等待）。

## 流程示意

```
/b50          扫码 -> 换凭证 -> 登录 -> 成绩接口 + 明细接口 -> 渲染 -> 回图 -> 登出
/fp           新码换 token -> 登录 -> 构建上传 -> 写入 -> 登出（每次新码）
```

## 凭证纪律

- `/b50` 每次使用新码换新 token；登录后**查询结束必登出**
  （UserLogoutApi 回传登录时刻，服务器按此校验会话）
- 登录态查询本地缓存 10 分钟（`records_cache.json`），同账号重复查询命中零登录
- 写命令每次新二维码换新 token，流程必须完整（登录 → 上传 → 登出），
  中间出错/中断会导致 isLogin=1（小黑屋，15 分钟冷却）
- isLogin=1 期间不要反复登录

## 小黑屋（isLogin）防护

若账号 banState=1（官方警告），连续登录/高频查询即触发小黑屋（15 分钟）：

- isLogin=1 = 服务器拒绝登录，等 15 分钟自动解除，不要反复尝试
- `/b50`：同账号 10 分钟内重复查询命中缓存零登录；登录后 finally 必登出

## CLI 等价（调试）

```bash
python b50_cli.py --uid 1234567          # 免登录渲染 B50（本地调试）
python b50_cli.py --qr <新码> --full     # 登录态增强渲染（查完自动登出）
```
