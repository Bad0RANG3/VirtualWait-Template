# services/bot — NoneBot2 插件（B50 / 写操作 / 队列通知）

VirtualWait QQ 机器人（services/bot，NoneBot2）：QQ 扫码查询完整 B50 成绩图（每次新码，查完自动登出）；
另有道具、成绩等写命令（**真实改写账号数据**）。

## 命令

| 命令 | 说明 | 登录 |
|------|------|------|
| `/help` | 全部命令说明 | - |
| `/b50 <二维码>` | 完整 B50 图（FC/AP/同步/DX 徽标，查完自动登出） | 登录态（每次新码） |
| `/fp <二维码> [2~5]` | 发票（库存 0 才下发，免费固定 1 张） | 写（每次新码） |
| `/giveitem <二维码> KIND:ID [...]` | 写道具 / 收藏品（一次最多 10 条） | 写（每次新码） |
| `/score <二维码> MUSIC:LEVEL:ACH[:COMBO[:SYNC]] [...]` | 传分（一次最多 5 个谱面） | 写（每次新码） |

> 群里需 @机器人；私聊直接发。写命令真实改写账号数据，确认是自己的账号再发。
> 写操作按机台时序走「结算 → 落库」，每档约 1~2 分钟（含服务器要求的 60s + 30s 等待）。

itemKind：1姓名框 2称号 3头像 4礼物 5歌曲 6Master 7Re:Master 8宴谱 9角色 10搭档 11背景板 12功能票

- 传分 `ACH` 可写 `1010000` / `101.0000` / `100.5%`；
  `COMBO`=0 无 1 FC 2 FC+ 3 AP 4 AP+；`SYNC`=0~5

## 流程示意

```
/b50       扫码 -> 换凭证 -> 登录 -> 成绩接口 + 明细接口 -> 渲染 -> 回图 -> 登出
写命令     新码换 token -> isLogin 探测 -> 登录 -> 查询快照 -> 60s
           -> 结算包（GetUserNewItemListApi，带本局 playlog）-> 30s
           -> UpsertUserAllApi（目标行 + 同一批 playlog）-> 登出（finally 必登出）
```

## 凭证纪律

- 每条命令都要机台登录界面的**新**二维码；换到 token 后登录即消耗该码
  （哪怕后续没发写包），失败要重新扫码
- `/b50` 登录后**查询结束必登出**（UserLogoutApi 回传登录时刻，服务器按此校验会话）
- 登录态查询本地缓存 10 分钟（`records_cache.json`），同账号重复查询命中零登录
- 写流程中途出错/被中断会导致 isLogin=1（小黑屋，约 15 分钟冷却）
- isLogin=1 期间不要反复登录，等冷却自动解除

## 小黑屋（isLogin）防护

若账号 banState=1（官方警告），连续登录/高频查询即触发小黑屋（约 15 分钟）：

- isLogin=1 = 服务器拒绝登录，等冷却自动解除，不要反复尝试
- `/b50`：同账号 10 分钟内重复查询命中缓存零登录；登录后 finally 必登出

## 实机结论（写能力的边界）

- 传分 / 发票已实机落地；`/giveitem` 尚待机台回查确认

## CLI 等价（调试）

```bash
python b50_cli.py --uid 1234567          # 免登录渲染 B50（本地调试）
python b50_cli.py --qr <新码> --full     # 登录态增强渲染（查完自动登出）
python b50_cli.py --qr <新码> --give-item 3:250103 --verify
python b50_cli.py --qr <新码> --score 417:3:101.0000:4:4 --dx-max
```

`python b50_cli.py --help` 列出全部写命令开关。
